# CodeFetch
This repository contains the CLI and VSCode extension releases to use with the the CodeFetch service.

## CLI

**Manual Install (Windows)**

```
iwr https://github.com/codefetch-io/codefetch-releases/releases/latest/download/install.ps1 | iex
```

**Manual Uninstall (Windows)**

```
iwr https://github.com/codefetch-io/codefetch-releases/releases/latest/download/uninstall.ps1 | iex
```
